C5JF02P0Dépose - repose : Support avant d’arche de toit escamotable
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Outillage préconisé
Figure : e5ap28vc
[ 1] Gabarit de positionnement 4709-T :
  • [1a] Gabarit de positionnement droit 4709-T.D
  • [1b] Gabarit de positionnement gauche 4709-T.G
2. Opération préliminaire
Déposer :
  • Le joint d’étanchéité (partiellement)
  • Les 2 pare-soleil
  • Les 2 supports de pare-soleil
Dégager partiellement la garniture supérieure intérieure.
3. Dépose
Figure : c4cp0xnc
Centrer l’outil [ 1b] sur le support avant d’arche de toit escamotable.
Régler :
  • " d" = Latéral (ajouter ou retirer des cales en "c")
  • "a" et "b" = Hauteur
Figure : c4cp0xpc
Déposer :
  • Les vis (1)
  • Le gabarit [1b] avec le support avant d’arche de toit escamotable
4. Repose
Figure : c4cp0xqc
Positionner le support avant d’arche de toit escamotable ( 2) sur le gabarit [1b].
Reposer l’ensemble sur le véhicule.
Poser les vis (1) Couple de serrage : 2,8 ± 0,7 m.daN.
